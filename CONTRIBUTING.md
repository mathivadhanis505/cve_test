Contributing to AutoPatcher
Thank you for your interest in AutoPatcher.
AutoPatcher is an educational open-source project maintained by the Developer Club, IIITDM Kancheepuram. It is designed to help students learn Python, DevOps, cloud infrastructure, GitHub Actions, and security automation through real-world contributions.
We welcome contributors of all experience levels.
---
Before You Start
Read the project README.
Check existing Issues before creating a new one.
If you are planning a large feature or significant change, start a discussion first.
---
Setting Up Your Development Environment
Fork the repository.
Clone your fork.
Create a new branch for your changes.
Install the required dependencies.
Configure your own environment.
AutoPatcher does not include deployment credentials or infrastructure.
You will need to configure your own:
`GH_PAT`
`POSTGRES_URL`
`SLACK_WEBHOOK`
`EC2_HOST`
`EC2_SSH_KEY`
The GitHub Actions workflow will not function until these values are configured.

Making Changes
Please keep pull requests focused on a single change whenever possible.
---
Coding Guidelines
Follow the existing project structure and coding style.
Write clean, readable, and well-documented code.
Use descriptive names for variables, functions, and files.
Keep your changes focused on a single feature or bug fix whenever possible.
---
Testing
Before submitting a pull request, ensure:
The project runs successfully.
Existing functionality is not broken.
Documentation is updated if necessary.
---
Commit Messages
Use clear and descriptive commit messages.
---

Pull Requests
When opening a pull request:
Clearly describe the changes you made.
Keep your pull request focused on a single change whenever possible.
Update documentation if necessary.
